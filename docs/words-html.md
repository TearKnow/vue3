## 页面概览

新概念英语 1–4 册词汇总表。按册浏览、按课分组展示单词（英文、音标、中文释义、可选例句），支持搜索、发音、自测、易忘词标记、连播、随机练习与课文阅读（2–4 册）。

顶部显示当前册 **课数 / 词数**（`PER` 统计，与过滤结果无关）。

| 册别切换 | 顶栏四册 Tab，切换后重绘列表并重算侧栏 |

## 词汇浏览

- **按课分组**：每课标题含课号标签（如 `1&2`）、中英文标题、本课词数。
- **单词卡片**：发音按钮、单词、音标、释义、右上角易忘星标；有 `e` 字段时显示例句。
- **分批渲染**：列表按课分批 `requestAnimationFrame` 插入，减轻首屏压力；恢复上次课位时用 `is-restoring` 先隐藏布局再跳转，减少闪动。
- **渲染中断恢复**：`sessionStorage` 标记未完成的渲染；刷新后若 60 秒内中断则回到「全部」而非错课位。

## 搜索与筛选

| 功能 | 说明 |
|------|------|
| 当前册搜索 | 顶栏搜索框，匹配单词 / 释义 / 音标（不区分大小写）；显示匹配条数 |
| 只看易忘 | 设置内开关，仅显示已标星词条；会重绘列表 |
| 自测模式 | 设置内「自测」：中文释义模糊，点击整张卡片揭示 |

## 按课导航

- **侧栏**：「全部」+ 各课芯片（课号 + 标题摘要）。
- **点击课**：滚动到对应 `#L{课号}`，顶栏下对齐（`headerOffset`）。
- **滚动联动（桌面）**：根据视口内课文高亮当前课，写入进度；滚到页顶视为「全部」。
- **滚动联动（手机）**：节流记录当前课，侧栏不高亮居中。
- **记忆**：当前册所选课写入 `localStorage` `nce4lessons`（每册一个课号或 `all`）；册别写入 `nce4book`。

## 发音

| 入口 | 行为 |
|------|------|
| 词卡 ▶ | 默认单次发音；开启连播时从该词起队列播放 |
| 试听框 | 任意输入 +「发音」/ Enter，不要求在词表中存在 |
| 英音 / 美音 | 设置内切换（`type=1` 英 / `2` 美），记忆 `nceVoice` |

- 播放中高亮当前 `.word.playing`；若卡片不在舒适视口内会轻滚跟随。
- 连播时对下一词 **预加载** 音频，减少等待。
- 同一词连读多次时处理 `ended` / `seeked`，避免只响一声。

---

## 连播（自动连播）

需在设置中勾选「连播」后生效：

- **顺序**：从点击的词起，按 `#content` 内 DOM 顺序至列表末尾。
- **间隔**：0.5–5 秒，步进 0.5，默认 2，存 `nceChainGap`。
- **连读**：每词 1–5 次，默认 1，存 `nceChainRepeat`。
- **中途**：再点其他词的发音会停旧队列、从新词重建。
- **不适用**：试听框、随机练习弹框内的发音不触发主列表连播。
- 连播开关刷新后默认关（不持久化）。

## 易忘词

- 点击卡片右上角 ☆ / ★ 切换，键名 `nceM_{册}_{课}_{词}`。
- 列表存 `localStorage` `nceMaster4`（JSON 数组）。
- 「只看易忘」依赖该列表过滤。

---

## 随机练习

- 顶栏「随机练习」打开弹框。
- 从**当前册**随机 **10** 词；展示拼写、音标、所属课、发音按钮。
- 释义默认模糊/隐藏，「显示翻译」或点击卡片揭示。
- 「换一批」重新抽样；遮罩点击关闭（pointerdown/up 防误关）。

---

## 课文阅读（2–4 册）

- 课标题旁文档图标（第一册无，因暂无 `public/nce/1/` 课文文件）。
- 点击异步 `fetch` `/nce/{册}/{课号}.json`，解析 `paragraphs` / `paragraphs_cn`（或 `text` / `text_cn`）。
- 弹框默认只显示英文；「显示翻译」展示中文段落。
- 同课内容内存缓存；切册关闭弹框；Esc / 关闭按钮 / 点遮罩可关。

## 本地存储一览

| Key | 内容 |
|-----|------|
| `nce4book` | 当前册 1–4 |
| `nce4lessons` | 各册上次阅读课号，如 `{"2":"15","3":"all"}` |
| `nceMaster4` | 易忘词 key 数组 |
| `nceVoice` | 1 英音 / 2 美音 |
| `nceChainGap` | 连播间隔（秒） |
| `nceChainRepeat` | 每词连读次数 |
| `nceOnlyMaster` | 是否只看易忘 |
| `nceRenderGuard` | `sessionStorage`，渲染中断检测 |

`localStorage` 不可用时降级为空，避免白屏。

## 技术约束

- **单文件**：样式、结构、数据、逻辑均在 `public/words.html`。
- **无构建依赖**：词表数据直接内嵌；课文依赖静态 JSON。
- **外链**：仅发音请求有道 API。
