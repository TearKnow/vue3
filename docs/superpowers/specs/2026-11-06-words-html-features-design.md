# words.html 词汇页增强设计

**日期**: 2026-11-06 | **状态**: 已确认  
**范围**: 仅改 `public/words.html`（单文件增强）

## 概述

在现有新概念英语词表页上增加四项能力：任意词发音、自动连播、左侧课文改为滚动定位、随机抽词练习弹框。沿用有道音源与现有 `localStorage`（易忘词 / 册选择），不拆文件、不迁 Nuxt。

## 已确认决策

| 项 | 决策 |
|----|------|
| 实现方式 | 方案 1：单文件内增强 |
| 自动连播顺序 | 从点击的词起，按当前主列表 DOM 顺序往后播，到末尾停止 |
| 连播间隔 | 当前词 `ended` 后再额外等 N 秒（页面步进器 1–5，默认 2，`localStorage`） |
| 每词连读 | 每个词连续播 M 次后再进下一个（步进器 1–5，默认 1，`localStorage`）；未勾选「自动连播」时两处设置不生效 |
| 随机词池 | 仅当前选中册 |
| 弹框展示 | 拼写 + 音标 + 发音；释义默认隐藏，点击揭示 |
| 弹框数量 | 固定 10 个 |

## 1. 自定义发音

- 位置：顶部搜索栏区域（搜索框旁或同行），新增「试听」输入框 + 播放按钮。
- 行为：读取输入文本（trim），非空则用现有 `play(w)` / 有道 URL，跟随当前英音/美音切换。
- 支持 Enter 键触发播放；词表内找不到该词也照样发音（纯音源请求）。
- 不写入易忘、不改列表过滤。

## 2. 自动播放开关

- 位置：顶部 controls，与「自测」「只看易忘」并列，文案如「自动连播」。
- 开启后：用户点击主列表某词的发音按钮时，以该词为起点，收集当前 `#content` 内 `.word` 的 `data-w` 顺序队列，从该索引连播到末尾。
- 节奏：`play` → 监听 `Audio.ended` → `setTimeout(间隔秒×1000)` → 同一词若未达连读次数则再播，否则进下一个；中途关开关则 `clearTimeout`、停止排队（`player.pause()`）。
- UI：「自动连播」旁两个购物车式步进器（间隔秒、连读次数）；值写入 `localStorage`（如 `nceChainGap` / `nceChainRepeat`），刷新保留；**仅勾选自动连播后**参与连播逻辑。
- 中途再点另一个词的发音：取消旧队列，从新词重建队列并开始。
- 自定义试听输入、随机弹框内的发音：**不触发**主列表连播（仅主列表 `.vbtn` / 等价入口触发）。
- 自动连播开关本身可不持久化（刷新默认关），避免误开连播。

## 3. 左侧课文：滚动定位

- 改 `pick(l)`：当 `l !== 'all'` 时，`cur` 保持 `'all'`（或不再用 cur 过滤单课），`render` 后 `scrollIntoView` / `scrollTo` 到 `#L{lno}`；侧栏高亮当前锚点课文即可。
- 「全部」：取消高亮锚点，滚回顶部，仍显示整册。
- 搜索 / 只看易忘 过滤逻辑不变；过滤后若点侧栏某课，仍跳到该课区块（若该课在当前结果中不存在则无操作或轻提示，实现时静默即可）。
- 不再出现「点一课后主区只剩该课单词」的过滤行为。

## 4. 随机 10 词弹框

- 入口：顶部按钮「随机练习」。
- 打开时：从当前册 `RAW` 中无放回随机抽 10 个（不足 10 则全抽）；弹框列表展示拼写、音标、发音按钮、易忘星标；释义默认模糊/隐藏，点击卡片揭示（可复用现有 quiz 揭示交互思路，但作用域限弹框内）。
- 星标：复用 `mkey` / `nceMaster4`，与主列表同步；弹框内点星即写入「只看易忘」集合。
- 操作：换一批（重新抽 10）、关闭；遮罩关闭须符合项目规范（`pointerdown.self` 记录 + `pointerup.self` 才关，处理 `pointercancel`），不用仅 `@click.self`。
- 弹框内发音不启动主列表自动连播。

## 非目标

- 不改词表数据源、不新增后端 API。
- 不把页面迁到 Nuxt / 不拆独立 JS 包。
- 不实现可配置抽词数量、跨册混抽、纯听写（不显示拼写）模式。

## 验收要点

1. 输入任意英文词可按当前口音发音。
2. 开「自动连播」后点某词：按设定间隔与每词连读次数顺序播至末尾；关开关立即停止；再点他词则改从新词连播；间隔/连读可步进调节并持久化。
3. 左侧点课文整册仍在，页面滚到对应课文；点「全部」回顶。
4. 「随机练习」弹出 10 词（当前册），释义默认藏，可发音、可标易忘、可换一批、可关弹框。
